# SentinelShield

SentinelShield is a practical cybersecurity project that demonstrates a lightweight intrusion detection and web protection workflow.

## Features
- request inspection
- signature-based detection for common web attacks
- rate limiting for suspicious traffic
- logging and dashboard summary
- simple web interface for practical demonstrations

## Run the project
1. Open a terminal in this folder.
2. Install dependencies:
   `python -m pip install -r requirements.txt`
3. Start the application:
   `python app.py`
4. Open the browser at:
   `http://127.0.0.1:5000`

## Run tests
- `python -m pytest -q`
